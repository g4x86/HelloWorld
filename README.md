# HelloWorld Shell Script

This is a hello-world shell script developed in both *Bash* and *Python* for a Linux distribution.

**Usage**

<u>Bash</u>

```shell
./helloworld.sh
```

<u>Python</u>

```shell
python3 helloworld.py
```

**Output**

The output message from both scripts looks like the following:

```
Hello world from Pop!_OS 22.04 LTS linux
```

**Environment**

<u>Bash</u>

*Bash* command interpretor and the following Linux commands are required for running this script:

-   `uname`
-   `cut`
-   `sed`
-   `lsb_release`

<u>Python</u>

A *Python* (virtual) environment with the following requirements:

-   *Python* version: 3.10+
-   *Python* modules: `sys` and `platform`
